Leitura de espectros Mössbauer

Do arquivo bruto a uma leitura mais clara.

MossView é uma ferramenta em Python que transforma contagens de arquivos .MOS em gráficos de transmissão relativa — e aproveita metadados de arquivos .JOB associados.

O que a ferramenta faz

Um fluxo direto, do arquivo à figura.

O MossView reúne leitura de dados, metadados disponíveis e um gráfico pronto para inspeção. Foi feito para rodar como script Python, sem depender de uma interface online.

01 — LEITURA

Entradas conhecidas

Leia contagens de um arquivo .MOS em XML ou texto numérico. Ao encontrar um .JOB relacionado, o programa pode aproveitar o título e o valor de VMAX.

02 — VISUALIZAÇÃO

Escala e transmissão

Gere uma escala linear de velocidade simétrica e normalize as contagens pelo máximo para exibir a transmissão relativa em porcentagem.

03 — ARQUIVO DE SAÍDA

PNG ao lado dos dados

Salve o gráfico na mesma pasta do arquivo .MOS. Uma janela Matplotlib também abre para visualização interativa.

04 — INCERTEZA

Erros de Poisson

Mostre barras calculadas como √contagem, também normalizadas pelo máximo da amostra.

05 — METADADOS

Contexto no gráfico

Quando disponível, exiba o título e inclua arquivo, JOB associado, número de canais, Vmax e contagem máxima no gráfico.

06 — INSPEÇÃO

Checagem pontual de .JOB

Compare alguns valores dentro do bloco &PARAM com valores de tabelas e, se houver correções, grave um arquivo -updated.job separado.

Como funciona

Quatro passos, sem mistério.

O próprio arquivo que você passa determina a busca pelos dados relacionados e onde o gráfico será salvo.

01 Entrada

Escolha o arquivo

Passe o caminho de um arquivo .MOS ou .JOB como argumento.

02 Associação

Localize o par

O programa tenta encontrar o .MOS e o .JOB correspondentes na mesma pasta.

03 Cálculo

Normalize os canais

Use contagens, escala linear simétrica e a maior contagem como referência.

Salve e inspecione

Grave um PNG junto aos dados e abra a janela interativa do gráfico.

Escopo e transparência

Ferramenta clara sobre o que faz.

O MossView é um visualizador local em desenvolvimento. Conhecer suas limitações ajuda a interpretar o resultado no contexto correto.

↗
Interface de linha de comando

Não há, no projeto atual, um visualizador no navegador nem uma interface gráfica própria. A visualização é aberta por uma janela interativa do Matplotlib.

↔
Escala linear simétrica

A velocidade é calculada de −Vmax a +Vmax. O valor padrão é 10 mm/s quando não há metadado aplicável. ND e TRIANG são lidos, mas ainda não alteram o processamento.

.MOS
Formatos de dados

O parser tenta ler XML com elemento <data> ou extrair números de texto simples; formatos mais complexos podem não ser reconhecidos.

.JOB
Checagem parcial, não validação normativa

A inspeção cobre casos numéricos selecionados dentro de &PARAM. Não valida todo o formato NORMOS nem garante correção física.

Revise arquivos corrigidos antes de reutilizar

Quando identifica diferenças, o programa cria uma cópia com sufixo -updated.job. A correção é heurística: confira os valores antes de enviar o arquivo a outro software.

Perguntas frequentes

Antes de começar.

Respostas rápidas sobre os limites atuais e o uso do MossView.

Posso enviar meu arquivo pelo site?

Não. Este site apresenta o projeto; ele não processa arquivos no navegador. Para visualizar um espectro, instale o MossView e rode o script localmente.

O MossView ajusta linhas ou determina parâmetros físicos?

Não. A funcionalidade documentada lê os canais e cria um gráfico de transmissão relativa com barras de erro. Não há ajuste de componentes espectrais.

Preciso de um arquivo .JOB?

Não para tentar ler os dados do .MOS. Quando um arquivo .JOB associado é encontrado, o MossView pode usar metadados para título e escala de velocidade, além de executar sua checagem limitada de parâmetros.

O que acontece com o arquivo original?

As correções heurísticas de parâmetros são escritas em um arquivo com sufixo -updated.job, para que você possa revisar a versão gerada. Inspecione-a antes de usar em outro programa.

Onde posso consultar o código e acompanhar o projeto?

O código-fonte, a documentação técnica e o histórico do projeto estão no repositório MossView no GitHub.
